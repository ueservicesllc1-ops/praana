## EmailJS configuration

The admin panel includes a **Test email** button and the public reservation form now send through EmailJS. Configure the following variables in `.env.local` before running the project:

- `NEXT_PUBLIC_EMAILJS_SERVICE_ID`
- `NEXT_PUBLIC_EMAILJS_TEMPLATE_ID`
- `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY`

Example:

```
NEXT_PUBLIC_EMAILJS_SERVICE_ID=service_1y0786u
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=template_3xe93cm
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=qiQ8ePjd70mK3bNGD
```

You can update the EmailJS template to match your reservation content; the app sends the guest name, reservation code, date, time, party size, phone, notes, and a management URL. Restart the dev server after changing environment variables.
